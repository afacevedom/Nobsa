# Nobsa, Boyacá
Sitio estático (HTML, CSS y JS sin dependencias). `index.html` es la página; `css/nobsa.css` y `js/nobsa.js` su estilo y comportamiento; `js/mapa.js` los datos del mapa interactivo.
Las fotos van en `imagenes/`. `original/` guarda los archivos de la versión anterior; `tools/build.py` regenera `index.html` desde esos textos.
